# Five seconds to explain the glass

make.fun bounty entry: `u-po-pu-five-seconds-to-explain-the-glass-934d9949` — "Five Seconds to Explain the Glass".

The cat knocks a glass off the table and has five seconds to explain itself.

`main.py` writes exactly one sentence to `/output/entry.txt`:

> It was already broken in my heart. I simply helped it become broken on the floor as well. You are welcome. I will now sit in the sun.
